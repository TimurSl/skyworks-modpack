# Changelog — Skyworks: Industrial Arcana

## Cybernetics questline rewritten for the current mod

* Create: Cybernetics no longer has parts of its own (copper wire, servos, casings, silicon, ink, coolant, nanites, echo
  lattice ...): implants are Mechanical Crafter recipes from Create and vanilla items, upgrades are sequenced assemblies of
  brass / golden / sturdy sheets, electron tubes, Precision Mechanisms, netherite and echo shards, with Bio-Interface and
  Neural Gel. Most of the old 41 quests asked for items that no longer exist ("Item is Missing"); the chapter is now 28
  quests (English and Russian) on the real chain. `tools/check_cyber_quests.py` fails when a quest item is not in the jar.
* Removed the `cyberimplants` item tags from skyworks-core (`exotics/*`, `composite_reinforcement`): the mod does not read
  them any more.
* Pack version and revision are bumped automatically (`tools/bump_version.py`, docs/UPDATES.md); `update.sh` ships everything.

## patch v5 — 2026-10-31: Create: Cybernetics, Backrooms polish, auto-update

Built by `scripts/make-patch-v5.sh` on top of patch v4 (`patches/v5/`, `build/Skyworks-patch-v5-{server,client}.zip`).

* **Create: Cybernetics** (see below) and the Backrooms polish from `a9d77a8` are in this patch.
* **Backrooms:** suffocation hardened (Water Breathing is stripped inside), mimic kill reach fixed, no fog in the huge rooms,
  ceiling-only lamps, `/backrooms refresh` (reload in place), cardboard-box barrels.
* **Skyworks Gate** (`src/gate`, own work, MIT, both sides): on join the client reports its pack revision
  (`pack.revision` in the manifest, 5 for this patch) and the server turns the player away with a message that says what to
  update when it differs, or when the client has no gate at all. Server config `config/skyworks_gate-common.toml`:
  `enforce`, `downloadUrl`. Bump `pack.revision` for every patch / publish players must have.
* **Auto-update** (`docs/UPDATES.md`): publish the pack as a packwiz pack; Prism and the server update before every start.
  Existing v1-v5 installs switch over once with the updater kits; there are no more patch zips after that.

## Create: Cybernetics + the Cybernetics questline

* **New mod: Create: Cybernetics** (`cyberimplants`, own work, MIT, bundled): cybernetic implants built on Create
  production lines, installed on a kinetic Implantation Rig and graded from Mk. I to Mk. V, plus programmable cyberdecks
  (Synapse) that read Create machines. `scripts/build-cyberimplants.sh` builds it from a sibling checkout
  (`../create-cyberimplants`, or `SKYWORKS_CYBERIMPLANTS_SRC`) or takes a ready jar (`SKYWORKS_CYBERIMPLANTS_JAR`, e.g. the
  mod's CI artifact) and registers it in the manifest; the client, server and export builds call it.
* **New quest chapter "Cybernetics"** (41 quests, English and Russian): basic Mk. I implants from andesite-age parts on the
  start island, then one row per grade (Industrial, Advanced, Military, Experimental) that says where each ingredient comes
  from in the sky world (quartz meteors, Skyworks slime and amethyst recipes, snow golems for coolant, ancient cities for
  echo shards, the fortress for blazes and the Wither) and what the Rig needs (RPM, gel). Optional and XP-only, like the rest.
* **skyworks-core tags for the mod's Tier V exotics** (`data/cyberimplants/tags/item`, generated by `tools/gen_recipes.py`):
  Trial Chambers, mansions and raids do not exist here and netherite is meteor-only, so Chemica carbon fibre (limbs,
  skeletal), phantom membrane (legs), charged amethyst (Defibrillator) and TFMG steel (composite plates) are accepted too.
  The original items still work.

## Auto-update (replaces patch zips)

  `Skyworks-updater-client.zip` / `Skyworks-updater-server.zip`. See docs/UPDATES.md.

## patch v4 — 2026-10-29: the Backrooms update (dweller 0.3.0) + HexQuantum + DOOM93

Built by `scripts/make-patch-v4.sh` on top of patch v3 (oxygen, death drops everything, amethyst from quartz).

* **New mod: HexQuantum 0.1.0** (own work, bundled): Hex Casting addon - illusions, echoes, phantoms, pocket space
  (its own `hexquantum:pocket` dimension) and quantum media. Loads with 0 errors on the dedicated server.
* **New mod: DOOM93 Mode 1.0.0** (own work, CLIENT_ONLY, optional; client patch only): F9 toggles a DOOM look - status bar,
  sprite weapons, view bob, Freedoom sounds, E1M1 on an OPL2 synth, palettized pixel screen. Own `DOOM.WAD` in
  `.minecraft/doom93/` swaps in the original assets.
* **Backrooms rework (МАХІТО's "Changes and Refinements", 2026-10-29)**, see docs/BACKROOMS.md:
  * **Entry**: falling into the void pulls you in 50 % of the time (was 10-90 % by health and food); always a random spot,
    now one that avoids the huge rooms and anything a structure filled. The elevator always works.
  * **Screen filters**: fall in from the Nether and the screen is red, from the End it is inverted (vanilla post effects,
    `FilterPayload`), until you leave.
  * **Dimension rebuilt**: y -80..79, bedrock at -65 and 65, wallpaper filler between, the maze at y 1..6. **Huge rooms**: 20 x 20
    chunks (in 40 % of 48 x 48-chunk cells), carved from y -64 to 64, crossed by a plus of 1-wide bridges at carpet height
    with hanging panels (`world.HugeRooms`, `HugeRoomFeature`). **Vanilla structures**: one of 1028 vanilla pieces
    (villages, bastions, ancient cities, trail ruins, trial chambers, mansion rooms, shipwrecks, ruined portals ...) in about
    1 chunk in 10, anywhere between the bedrock layers, half placed whole, half only into air (stuck in the walls); never in
    a huge room's own chunks (`StructuresFeature`). New tile styles: closed corridors, a dead-end maze, combs of dead ends,
    big empty rooms (56 tiles, 12 styles). The old Backrooms of an existing world are wiped once automatically
    (`backrooms_layout.txt`, layout 2).
  * **Exits** replace the void pits: floor exits and rifts (a white line in a gap of a wall) in 4 rare tiles (~1 per 840
    chunks). Real ones: a random safe spot on the overworld's islands (searched, never over the void); a rift 20 % of the time
    the starting island. Half are decoys: a new random spot in the Backrooms at least 2000 blocks away.
  * **Cardboard boxes** (1x1 and 2x2): Ancient City loot, 50 % a bonus roll of any of 56 vanilla chest tables, 1-2
    **transcendent space-time glue**. The eye of ender recipe is now ender pearl + blaze powder + glue (vanilla's replaced).
  * **The stalker** is reworked: exactly one per Backrooms; appears ~100 blocks out, tracks at ~50, prefers lone players;
    phase 1 watches from the edge of their view while a gauge fills (90 s, faster with insanity), phase 2 walks at them and
    strikes for 1 heart of true damage, then flees 50 blocks. Looked at, it turns invisible and backs off; it never
    teleports. Only fire hurts it (flint and steel and fire charges now work in the Backrooms despite Adventure mode); the
    next one comes 60 s after it burns. No drops. Peeking from corners is gone.
  * **Mimics** (`skyworks_dweller:mimic`): wear the skin and name of someone who is or was on the server (never two the same
    player; 20 % blank), talk in chat in that player's words; kill on the spot whoever stays within 10 blocks for 60 s (through
    armour and totems); drop one random item from that player's inventory. **Mimic NPCs** look the same, follow players, harmless.
  * **Insanity** replaces hunger-based madness: tanks' worth of air breathed in the Backrooms (counted by backrooms.js, across
    tank swaps). Levels 1-5 at 10/20/40/60/80 %: phantom hits and whispers (40-200 s), quiet whispers, louder whispers and more
    mimics, then constant whispers, random harmless one-second effects and client-only phantom blocks, figures and dead ends.
    The knife works from insanity 4.
  * **Elevator** reworked into a two-person winch: an operator outside the surface cab drags the panel's handle round,
    clockwise to send it down (80 s, -10 s per extra rider), counter-clockwise to bring it up (80 s, +20 s per rider). No timers,
    no buttons below; the landing cab exists only while the cab is down; the surface cab can be blown up, the landing can't.
  * Ops: `/dweller insanity [set]`, `/dweller stalker summon|remove|status|attack`, `/dweller mimic spawn|npc`,
    `/dweller exit real|decoy floor|rift`, `/dweller room`, `/dweller elevator wind <id>`.
* **Monsters**: the wretch (80 hp, 9 damage, slow to notice) and the hound (36 hp, fast, keen ears), our own models and
  skins, spawned near players (max 2 each, never near a landing, never saved), with their own drops (pearls, echo shards ...).
* **Stealth**: sight cones, light, sneaking, footsteps and fight noise decide whether a monster notices you; idle /
  suspicious / hunting / searching; x2 damage on a monster that isn't hunting you; a stealth eye on the HUD.
* **Loot**: Lootr chests and barrels in the maze (about 0.25 per chunk) from three tables: supply (food), cache (pearls, blaze
  rods, eyes of ender, Create parts, Hex materials, a full spare backtank), vault (Hex Casting great spell scrolls, rare Create
  gear, totems). Container placement doesn't change any tile's walls and never blocks a corridor.
* **/backrooms reset [confirm|cancel]**: wipes the dimension when the server stops so it generates again (players taken out
  first, cabs recalled, logged-out players relocated on login).
* **No darkness effects**; no blindness on arrival.
* **Food works in the Backrooms** again (it was nullified); starvation there is still lethal.
* `tools/backrooms_inspect.py` understands the new layout: huge rooms and bridges, structures (their changes are not errors),
  boxes, exits, containers and elevator landings, and checks connectivity per region.
* Verified on a dedicated server (`devlog/test-runs/20261029-12*-br4.md`): everything loads, 20 TPS (Backrooms 0.3-1.3 ms/tick
  with 300 chunks force-loaded), box loot rolls, the inspector passes (all 273 arrival corners open, one connected maze,

### patch v1c

* Overworld islands rebuilt as explicit cones on a 2D Lithostitched `cellular` grid (tools/gen_worldgen.py,
  params `islands`): at most one island per 128-block cell (nearest centres >= 64 blocks by construction, measured
  >= 79), top radius 12-19 (measured r_eq 11.2-17.4), depth 1.6 x radius, flat-domed top, 2D-only edge wobble so an
  island is always one piece. No big islands, no fragments < 20 blocks (0 in a 784x784 sample, was ~300).
  Void seas and the 1000-block spawn clearing veto cells instead of cutting islands. RFI's 3D island noise, height
  offset, rivers and vertical band are gone. Interpolation cells 4 blocks; ore veins and overworld carvers disabled.
* Ores: every overworld ore's expected vein count = vanilla density x 0.3 (rescaled to the island band) - ores
  ~1.2 % of island blocks, <= 1.9 % on any island (was ~14 %). Nether quartz back to vanilla density.
* Nether islands use the same cones, rarer (192-block grid) with radius parameter 15-17 (measured 10.9-15.3); no
  nether carvers or basalt columns/pillars (floating crumbs). Meteor templates keep only their face-connected body
  and have half the quartz ore.
* Quartz meteors: overworld 1 per 300 chunks (was 90), new Nether placement 1 per 40 chunks (y 20-110).
* Less dense islands: grid 160 (was 128), chance 0.5 (was 0.6) - 9 instead of 19 islands per 784x784 blocks,
  nearest centres >= 114 blocks (devlog/worldgen/o3.json).
* tools/world_inspect.py: islands3d reports r_eq, ore_pct per island, fragments < 20 blocks, border-clipped islands
  and centre gaps; snow layers, tree parts, vines and geode blocks no longer count as terrain.
* Questbook: island descriptions (welcome, island hopping, void seas, Hex amethyst) updated EN/RU.

## 0.1.0-dev (cont.) — 2026-10-26: dweller 0.2.0 — stalker, chat mimic, Backrooms fixes

* **Stalker** (`skyworks_dweller:stalker`): follows its player at ~14 blocks, walking only while they walk. Its
  footsteps are played on the exact tick of the player's own steps (louder than theirs, only for them, sometimes one
  step too many after they stop). Drawn only at the edges of the screen like the dweller, never in the direct gaze.
  Looked at, it is teleported 48-80 blocks away at once and walks back towards the player. Now and then it hides
  behind a wall corner in the part of the screen where it is drawn and leans out for ~3 s.
* **Dementia levels** in the Backrooms (0-5, by time spent there, reset on leaving): more dwellers, stalkers and mimic
  lines, scary vanilla sounds behind you, whispers around you (synthesised). Config `[dementia]`; ops
  `/dweller dementia [set <level>]`. From level 4 the mimic also starts conversations (`mimicStartLevel`).
* **Backrooms music**: The Caretaker - Everywhere At The End Of The Time, split into its 12 chapters, streamed by the
  client in the Music category while in the Backrooms (vanilla music silenced). `music/` and the generated audio are
  gitignored; `tools/gen_dweller_audio.py` builds them.
* **Telegram bridge: KsuChat 1.0.2** (server only; `config/ksuchat.toml` in `server/config/`, which is gitignored and never
  exported: it holds the bot token). Forwards global chat, joins/leaves, deaths and advancements to a Telegram chat and
  Telegram messages into the game. It cancels the vanilla chat event and re-sends chat itself, so the mimic now also
  listens to cancelled chat events, and Backrooms chat is isolated (`isolateChat`): shown only to players in the
  Backrooms, never seen by the bridge. Still forwarded from the Backrooms: joins/leaves, deaths and advancements (the
  events can't be hidden; set `forwardDeaths = false` in `ksuchat.toml` if the death messages give too much away).
* Stalker peeks follow the player's own FOV setting: the client sends FOV, window aspect and edges to the server
  (`ViewPayload`), which places peeks in the part of that player's screen where the stalker is drawn.
  `peekMinDegrees` / `peekMaxDegrees` are gone.
* Chat bridges: the mimic's lines go straight to the haunted player's connection (no broadcast, no chat event), are no
  longer logged to the console / `latest.log` (now `<world>/skyworks_dweller/mimic.log`), and `/dweller mimic say` no
  longer echoes them to ops. No bridge mod is in the pack.
* Mimic: never imitates a player who is in the Backrooms (including the haunted one), and only answers: it no longer
  starts conversations (`startConversations`, `allowSelf` in `skyworks_dweller-common.toml`).
* Backrooms fog: a thick client-side fog hides everything beyond 2 chunks (`skyworks_dweller-client.toml` `[fog]`).
* Backrooms pits (the way out) are 3x rarer: about 1 per 440 chunks instead of 1 per 150 (new chunks only).
* Dying in the Backrooms now costs everything you carried (items and XP drop where you die); the old
  keep-and-restore behaviour is `keepItemsOnDeath = true` in `backrooms.js`.
* **Chat mimic**: chat lines that look like they come from real players, shown only to a player in the Backrooms.
  Per-player word-level Markov chain (order 2, both directions) trained on their recorded chat, grown from words of
  the conversation (with light stemming for Russian); the imitated player's own reply delays, message rate and
  bursts; naming a player makes that player "answer". Sent as `<Name> text` with the vanilla name styling. Chat Heads
  shows their head, also for offline players (an unlisted player-list entry for two minutes). Chat is recorded to
  `<world>/skyworks_dweller/chat/`. Ops: `/dweller mimic say|generate|stats|forget`, `/dweller stalker
  summon|remove|peek`.
* Fix: dying in the Backrooms dropped everything into the void instead of keeping it, and the "You wake up…"
  message never appeared. KubeJS's Rhino throws "redeclaration of var" for a block-level `const` in a function
  that also contains an inner function (reproduced standalone). The drops hook hit it on every death and fell back
  to normal drops. Now `let`. The wake-up line is also shown when there was nothing to restore.
* Fix: `/summon skyworks_dweller:dweller` in the Backrooms was silently cancelled by `backrooms.js`'s spawn check
  (it still printed "Summoned"; the mod's own spawner and `/dweller summon` were unaffected). Every
  `skyworks_dweller:` creature (dweller, stalker) is now exempt from both of its spawn filters. Verified on the server
  with frozen ticks: both summon paths keep the dweller and the stalker, and a zombie is still blocked.

## 0.1.0-dev — 2026-10-24/25 (first development build)

### Milestone A — core compatibility
* Project layout (`manifest/`, `scripts/`, `tools/`, `src/`, `docs/`), git repository, GC-rooted Java 21.
* `tools/manifest.py`: single authoritative mod manifest (pin by Modrinth version or URL, SHA-512/SHA-1, side,
  licence), hash-verified fetch, jar-metadata dependency checker (incl. jar-in-jar, language providers,
  Maven version ranges), per-side install.
* Dedicated server builder + low-priority lifecycle scripts (systemd user unit, 4 GB heap, cgroup limits, RCON).
* Create 6.0.10, Sable 2.0.6, Create Aeronautics 1.3.2 — server boots (7 s), restart verified.

### Milestone B — essential gameplay
* Create Big Cannons 5.11.7 (+ RPL), Hex Casting 0.12.0-devel-pre-64 (official CI) + PAUCAL, Patchouli, Caelus,
  Inline, Curios, Cloth Config, Architectury, Kotlin for Forge (found missing by a failed boot).
