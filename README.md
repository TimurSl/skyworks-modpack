# Skyworks - Industrial Arcana: modpack download

Minecraft 1.21.1 / NeoForge 21.1.264 / Java 21. Pack version 0.1.2-dev+20261031.0447.

## Play (Prism Launcher)

1. Download **[Skyworks-Prism.zip](https://raw.githubusercontent.com/TimurSl/skyworks-modpack/main/Skyworks-Prism.zip)**.
2. In [Prism Launcher](https://prismlauncher.org/): *Add Instance* -> *Import* -> pick the zip.
3. Press *Play*. The first launch downloads the whole pack (a window shows the progress), and so does every launch after
   that, but only for what changed. You never have to update by hand.

Files you add yourself (extra mods, shaders, resource packs) are kept.

## Play on Android (Zalith Launcher 2 / PojavLauncher)

1. Download **[Skyworks-mobile.mrpack](https://raw.githubusercontent.com/TimurSl/skyworks-modpack/main/Skyworks-mobile.mrpack)** to the phone.
2. In Zalith Launcher 2: import the downloaded file as a modpack and pick it.
3. This build leaves out Sodium, Sodium Extra, Reese's Sodium Options, ImmediatelyFast, Entity Culling and Dynamic FPS:
   they need desktop OpenGL and break on Android. Zalith has no auto-update: to get a new pack version, download the
   file again and import it as a new version.

## Servers

Use the server zip from the project releases; it updates itself from this repository on every start.

## For the curious

This repository is generated by CI ([packwiz](https://packwiz.infra.link/) format): `pack.toml` is the entry point,
`mods/` lists every mod with its download link and hash, `blobs/` holds the jars that have no public download. Do not
edit it by hand: every publish replaces it.
